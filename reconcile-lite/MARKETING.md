# 맞춰봄 무료 베타 — 14일 수요 검증 (2026-11-20~2026-12-04)

## 가설
공통 거래번호가 있는 주문별 정산 예정 파일과 정산 확정 파일을 반복 비교하는 온라인 판매자/정산 담당자 중 일부는 무료 자동 대사 도구를 쓰고 유료 맞춤형 형식 대응에 관심을 보인다.

## 기능의 진짜 범위
- 원본 CSV/XLSX 두 파일은 브라우저에서 처리하며 서버에 전송하지 않습니다.
- 사용자는 거래번호 및 비교할 금액 열을 선택합니다.
- 동일 키별로 합산 후 누락/차이를 보여 줍니다.
- **은행 입금 전체와 주문 개별 행 사이의 관계를 자동으로 추론하는 서비스가 아닙니다.**
- 파일이 서버에 올라가지 않으므로 오류 보고시 실거래 파일 첨부 금지.

## 14일 실행계획
- 1일: 샘플 데모/직접 파일 사용, 공유 문구 검증.
- 2~4일: 정산 실무 경험자에게 1:1로 5명 요청. 3분 인터뷰: 비교하는 두 파일의 종류, 공통 키, 현재 걸리는 시간, 다시 쓸지.
- 5~7일: 디스콰이엇 제품 등록 및 홍보 허용 커뮤니티에 글 1건씩, 서비스 링크를 정보성으로 제공.
- 8~14일: 실제 분석 횟수와 비정상 데이터 오류/불일치 원인 피드백 평가. 가격은 구매 의사를 직접 묻는 방식으로 검증하고 매출로 기록하지 않음.
- 무료 홍보/게시 정책 확인 후 게시; 스팸성 반복/무단 DM/침투 바이럴 금지.
